# TeamLingua

免费的团队职场英语练习网页。[打开网站](https://teamlingua.github.io/)

TeamLingua is a free web app for small teams to practise workplace English. The interface is currently in Simplified Chinese.

## 这是什么

TeamLingua 给小团队一起练习职场英语用：听、说、读、写，题目偏向真实上班场景，而不是考试卷。不用下载，用浏览器打开即可。也可以先做一道题，再决定要不要注册。

This is a practice tool, not an exam prep site, and not a paid course.

## 现在已有的功能

- 听 / 说 / 读 / 写练习，场景来自真实工作，例如请假、订会议室、请人看邮件
- 未注册可以先试一道题
- 积分；当天累计学习满 20 分钟额外奖励 10 积分
- 打卡连签
- 积分达到 100 后，可以免费领养一只宠物
- 练习结果卡，可以向朋友发起挑战
- 邀请队友：对方注册并完成首日 20 分钟学习目标后，邀请人获得积分（自己的小号或同一设备上注册的账号不算）

以上都是网站里已经有的功能。这里不写用户数量或学习效果，因为那不是现在能诚实提供的数据。

## 使用

1. 打开 https://teamlingua.github.io/
2. 可以先点「先试一道题（不用注册）」
3. 觉得合适再注册，之后可和队友一起练习

## 目前的限制

- 界面目前是简体中文，没有语言切换
- 这是个人业余项目，免费使用，没有付费墙
- 网站托管在 GitHub Pages
